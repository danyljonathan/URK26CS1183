# Campus Lost & Found Portal

Frontend Web Technology microproject using HTML5, CSS3 and Vanilla JavaScript.

## Run
1. Extract this ZIP and open the `campus-lost-found` folder in VS Code.
2. Open `index.html` with Live Server (recommended), or directly in a browser.
3. Register an account, sign in, report lost/found items and browse listings.

## Files
- `index.html`: landing page
- `register.html`, `signup.html`, `signin.html`: account pages
- `home.html`: dashboard and calculator
- `report-lost.html`, `report-found.html`: reporting forms
- `items.html`: searchable item listings
- `style.css`: shared responsive styling
- `script.js`: validation, LocalStorage, reports, filters and dashboard
- `theme.js`: persistent theme toggle
- `chatbot.js`: keyword-based assistant
- `calculator.js`: calculator with zero-division handling

## Important demonstration notes
This is a frontend-only prototype. LocalStorage is specific to the browser and device; it is not a shared campus database. Passwords are stored in LocalStorage for demonstration only, so use fictional demo credentials and never enter real passwords. Uploaded images are stored in browser LocalStorage as data URLs and limited to 1.5 MB.
